Build on Prisma 8 `8.0.0-rc.18`. The PSL reader uses the namespaced symbol table and reads enum members from block entries, so enum diagnostics point at the member when the provider passes the parsed `sources`. Contract sources declare `format`. The control instance implements `signSpaces` (a refusal, like `sign` before it) and `storageNameOf`. List fields are emitted as `many: { elementNullable: false }`, and execution defaults as `{ namespace, entry, field }`. `migration plan` passes `origin` and `statements` to the planner.
